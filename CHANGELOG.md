# История версий AquaControl Pro

Формат: версия (номер сборки) — дата — что изменилось.
`versionCode` (номер сборки) обязан расти при каждом выпуске, иначе Android не установит обновление.

---

## 1.0.29 (build 30) — в работе

Первая версия из плана подготовки к массовому использованию.

Интерфейс:

- своя иконка приложения вместо стоковой картинки с водяными знаками;
- можно указать реальную дату последней замены — при создании фильтра, при замене
  и при исправлении в «Изменить фильтр»;
- «Настройки» → «Когда напоминать»: промежуток суток (утро 9:00–12:00, день 14:00–17:00,
  вечер 19:00–21:00) и предупреждение заранее (не нужно / 3 / 7 / 14 дней);
- на главном экране появляется заметная полоса, если Android запретил уведомления
  или экономия батареи может их задержать — одно нажатие ведёт в настройку;
- при первом запуске сначала показывается объяснение, зачем нужны три разрешения,
  и только потом по кнопке открываются системные окна Android;
- «Настройки» → «О приложении»: версия, ссылка на политику конфиденциальности,
  «Что нового», напоминание о резервной копии;
- тестовые сроки в минутах убраны из обычного режима
  (включаются семью нажатиями на строку с версией).

Исправления:

- нажатие на уведомление больше не помечает фильтр просроченным
  (раньше открытие старого уведомления портило отсчёт);
- названия домов, фильтров и брендов экранируются — символы `<`, `>`, кавычки
  больше не ломают разметку;
- в записи истории сохраняются дом, фильтр и дата числом, в списке видно, к какому дому относится замена.

Сборка:

- версия берётся из `version.json`, сборка падает при расхождении с `index.html`;
- перед сборкой прогоняется `tools/selftest.js`;
- иконки собираются из четырёх подготовленных файлов, поэтому иконка в лаунчере
  и в списке приложений настроек телефона выглядит одинаково;
- приложение больше не открывает системные экраны разрешений при первом запуске.

## 1.0.28 (build 29) — последняя проверенная на телефоне

- разгружена верхняя панель;
- видимый статус запрета разрешений;
- исправлен значок «Изменить»;
- автоматическая публикация APK в GitHub Releases при push в `main`.

## 1.0.27 (build 28)

- исправлено: кнопка «Открыть настройку» для батареи не реагировала, если разрешение уже выдано
  (теперь открывается общий список настроек батареи);
- добавлена проверка разрешения на показ уведомлений;
- действия с фильтром заменены строкой компактных значков;
- добавлен раздел «Настройки» (уведомления и резервное копирование);
- главный экран стал заметно короче.

## 1.0.26 (build 27)

- экран «Настроить уведомления»;
- подсказки по автозапуску для популярных прошивок;
- кнопки прямого перехода в нужный экран системных настроек;
- проверка уже выданных разрешений;
- переключение домов свайпом влево/вправо и точки-индикаторы.

## 1.0.25 (build 26)

- экспорт резервной копии в настоящий файл через системное окно Android (Storage Access Framework);
- сохранение в память телефона или в облако;
- имя файла содержит дату и время — копии не перезаписывают друг друга;
- копирование текста вручную осталось запасным вариантом.

## 1.0.24

- удалена Dev-панель;
- раздел «Резервная копия» стал сворачиваемым;
- введён процесс разработки небольшими безопасными изменениями;
- создан `AI_GUIDE.md`.

## 1.0.23

- исправлен запуск приложения;
- рабочий экспорт и импорт резервной копии;
- версия стала новой базовой точкой разработки.

## 1.0.22

- неудачная экспериментальная версия: попытка добавить нативные плагины, приложение падало при запуске.
  Вывод занесён в правила проекта: новые плагины — только при реальной необходимости.

## 1.0.21

- экспериментальная версия, начало разработки экспорта и импорта. Как стабильная не использовалась.

## 1.0.20

- стабильная подпись APK;
- исправлены проблемы с уведомлениями;
- подтверждена корректная установка поверх предыдущих версий.
