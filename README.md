# AquaControl Pro

Android-приложение для учёта сроков замены картриджей фильтров воды.

Работает полностью на телефоне: без сервера, без регистрации, без рекламы и без доступа в интернет.

**Текущая стабильная версия:** 1.0.28 (build 29)
**Пакет:** `com.aquacontrol.pro`
**Статус:** работает на устройстве владельца; подготовка к публикации в RuStore — см. `RUSTORE.md`

---

## Возможности

- несколько объектов (квартира, дача, родители), переключение свайпом;
- несколько фильтров в каждом объекте;
- автоматический расчёт срока замены с учётом жёсткости воды и количества человек;
- крупный счётчик оставшихся дней, цветные метки «скоро» и «просрочено»;
- напоминание в день окончания срока и повторное через 7 дней;
- кнопка «Отложить» на 15 дней;
- история замен и учёт расходов;
- быстрый переход в магазин по сохранённой ссылке;
- резервная копия в файл и восстановление из файла;
- помощник настройки разрешений Android (уведомления, батарея, автозапуск);
- работа без подключения к Интернету.

---

## Технологии

HTML + CSS + Vanilla JavaScript в одном файле `index.html`
→ Capacitor 5.7 (Android WebView) → APK через GitHub Actions.

Плагины: `@capacitor/local-notifications`, `@capacitor/browser`. Больше ничего.

---

## Хранение данных

Всё локально, `localStorage`, ключ `aquaControlProDB`. Данные не покидают устройство.
При обновлении приложения поверх предыдущей версии сохраняются; при удалении приложения — теряются
(поэтому есть экспорт в файл).

## Сборка

| Что | Workflow | Когда запускается | Результат |
|---|---|---|---|
| Отладочный APK (для себя) | `Build Native Android APK` (`build.yml`) | автоматически при push в `main` + вручную | debug-APK, GitHub Release |
| Релизный APK (для магазина) | `Build Release APK (RuStore)` (`release.yml`) | только вручную | release-APK, подписан постоянным ключом, `debuggable` отсутствует |

Actions: https://github.com/Help-yourself-dvp/water-filter/actions

Версия задаётся в `version.json` и обязана совпадать со строкой версии в `index.html` —
релизная сборка это проверяет и падает при расхождении.
