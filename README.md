# AquaControl Pro

AquaControl Pro — нативное Android-приложение для учёта сроков замены картриджей фильтров воды.

Проект предназначен для личного использования и работает полностью локально, без сервера и без регистрации.

---

## Возможности

- Несколько объектов (квартира, дача, родители и т.д.)
- Несколько фильтров в каждом объекте
- Автоматический расчёт срока замены
- Учёт жёсткости воды и количества пользователей
- История замен
- Учёт расходов
- Быстрый переход в магазин по сохранённой ссылке
- Экспорт резервной копии в файл и восстановление из файла
- Локальные push-уведомления
- Помощник настройки разрешений Android
- Работа без подключения к Интернету
