## 0. Сделать обязательно перед первой публикацией

1. **Скачать резервную копию ключа подписи** и сохранить вне GitHub (облако + офлайн).
   Потеря ключа = невозможность обновлять приложение у всех пользователей.
   Владелец попросил напомнить об этом перед публикацией — напоминание живёт здесь и в `AI_GUIDE_AQUACONTROL.md`.
2. Зарегистрировать аккаунт разработчика (проверка личности до 2 рабочих дней).
3. Слить рабочую ветку в `main` — только тогда заработает страница политики конфиденциальности
   и станет доступен ручной запуск релизной сборки.

## 2. Можно ли вам вообще публиковать

- Публикация в RuStore **бесплатна**.
- Зарегистрироваться может **физическое лицо** (проверка личности через паспорт/биометрию в консоли),
  ИП или юрлицо. Для ИП и юрлиц нужна УКЭП.
- Деньги (платные приложения, встроенные покупки) доступны только ИП, юрлицам и самозанятым.
  Нам это не нужно: приложение бесплатное и без рекламы.
- Альтернативы, если что-то не сложится: **NashStore**, **AppGallery** (Huawei), **GetApps** (Xiaomi),
  а также прямая раздача APK ссылкой на GitHub Release. В Google Play с 2025 года нужна верификация
  личности разработчика и `targetSdk` заметно выше — это отдельная история, не первым шагом.

Консоль разработчика: https://console.rustore.ru/

## 3. Регистрация разработчика (делаете вы, ~20 минут)

1. Открыть https://console.rustore.ru/ и войти через VK ID (или почту/телефон).
2. Выбрать тип: «Физическое лицо».
3. Пройти подтверждение личности (паспорт + селфи по инструкции консоли).
4. Принять оферту разработчика.
5. Дождаться подтверждения аккаунта (обычно от нескольких часов до 2 рабочих дней).

## 4. Сборка релизного APK (делаю я / запускаете вы одной кнопкой)

Важное про ключ подписи:

- Ключ у вас уже есть — он в секрете репозитория `DEBUG_KEYSTORE_BASE64`.
- Мы **сохраняем именно его**. Тогда новая релизная версия установится **поверх** той,
  что сейчас стоит у вас на телефоне, и данные не потеряются.
- Если ключ поменять — приложение придётся удалять и ставить заново, а после публикации в магазине
  смена ключа означает потерю всех пользователей. Поэтому: **ключ не менять никогда.**
- **Обязательно скачайте копию ключа и сохраните вне GitHub.** Как: вкладка Actions →
  workflow «Generate Stable Debug Keystore» → он выдаёт файл артефактом. Если ключ уже терялся —
  напишите мне, разберёмся отдельно.

Порядок сборки:

0. Кнопка «Run workflow» появляется только у сборок из ветки `main` — так устроен GitHub.
   Пока работа идёт в рабочей ветке, релизная сборка запускается изменением файла
   `release.trigger` (это делает AI). Проверено 17.08.2026: сборка проходит,
   подпись совпадает с ключом, отладочный режим выключен.
1. Открыть https://github.com/Help-yourself-dvp/water-filter/actions
2. Слева выбрать **Build Release APK (RuStore)**.
3. Кнопка **Run workflow** → ветка `main` → **Run workflow**.
4. Дождаться зелёной галочки (~4 минуты).
5. Готовый файл появится:
   - в разделе Artifacts этого запуска;
   - и в https://github.com/Help-yourself-dvp/water-filter/releases (если включили публикацию Release).
6. В логе шага «Проверка подписи и debuggable» посмотреть отпечаток сертификата (SHA-256) —
   он должен совпадать при каждой следующей сборке. Запишите его один раз себе.

Workflow сам остановится с ошибкой, если: ключа нет, версия в `index.html` не совпадает с `version.json`,
или в APK остался `debuggable`.

## 5. Политика конфиденциальности

- Текст: `PRIVACY.md`
- Готовый PDF для публикации: `store/AquaControl-privacy-policy.pdf`
- Инструкция, куда выложить (Яндекс Диск, статья ВКонтакте, GitHub Pages):
  `store/policy_for_web.txt`
- В самом приложении политика уже есть и работает без интернета.

Проверьте, что ссылка открывается в браузере **без входа в аккаунт** (режим инкогнито) —
модератор проверяет именно это. Telegra.ph не используем: в России открывается не у всех.

Ссылку нужно указать в карточке приложения в RuStore (поле «Политика конфиденциальности»).

Внутри приложения ссылок наружу нет: с версии 1.0.36 полный текст политики открывается
отдельным экраном в самом приложении («Настройки» → «О приложении» →
«Политика конфиденциальности») и работает без интернета. Публичная страница нужна
только для карточки магазина.

## 8. Готовые тексты карточки

**Название (до 50 символов):**

```
AquaControl — замена фильтров воды
```

**Краткое описание (до 80 символов):**

```
Напомнит, когда менять картридж фильтра воды. Без интернета и регистрации.
```

**Полное описание (до 4000 символов):**

```
AquaControl помогает не забыть о замене картриджа фильтра для воды.

Приложение считает срок службы за вас и присылает напоминание, когда картридж пора менять.
Всё работает без интернета, без регистрации и без рекламы: данные хранятся только на вашем телефоне.

ЧТО УМЕЕТ

• Несколько объектов — квартира, дача, дом родителей. Переключение свайпом.
• Несколько фильтров в каждом объекте: кувшин, проточный, обратный осмос, насадка на кран.
• Автоматический расчёт срока службы с учётом жёсткости воды и количества человек в доме.
• Крупный счётчик оставшихся дней прямо на главном экране.
• Напоминание в день окончания срока и повторное напоминание, если замена откладывается.
• Кнопка «Отложить», если картридж пока менять не планируется.
• История замен с расходами: видно, сколько потрачено за год.
• Ссылка на магазин для каждого фильтра — покупка нужного картриджа в один тап.
• Резервная копия всех данных в файл и восстановление из файла.
• Помощник настройки Android: подскажет, какие разрешения включить, чтобы напоминания приходили вовремя.

ПОЧЕМУ БЕЗ ИНТЕРНЕТА

Приложению не нужны ни ваш аккаунт, ни доступ в сеть. Оно ничего не отправляет и ничего не собирает.
Список ваших фильтров и дат остаётся на телефоне. Если вы меняете телефон — сделайте резервную копию
в файл и восстановите её на новом устройстве.

ДЛЯ КОГО

Для тех, у кого дома стоит фильтр и кто регулярно ловит себя на мысли «кажется, картридж пора менять
уже пару месяцев как».

О ТОЧНОСТИ РАСЧЁТА

Срок службы рассчитывается от значения, указанного производителем картриджа, и корректируется
по количеству человек в доме и жёсткости воды. Это оценка, а не лабораторное измерение: ориентируйтесь
также на вкус воды и напор.

Приложение бесплатное, без рекламы и встроенных покупок.
```

> Текст можно вставлять как есть. Если захотите — замените «человек в доме» на «жильцов»
> и добавьте свои формулировки; модерация читает описание целиком, поэтому перечитайте его перед отправкой.

**Категория:** «Дом и быт» (или «Инструменты», если первой нет в списке).

**Возрастной рейтинг:** 0+ (нет пользовательского контента, покупок, рекламы и внешних ссылок,
кроме той, которую пользователь сам вписывает).

```
Первая публикация в RuStore.
```

## 9. Раздел «Безопасность данных пользователя»

В консоли попросят перечислить разрешения и объяснить их. Готовые формулировки:

| Разрешение | Объяснение для модератора |
|---|---|
| `POST_NOTIFICATIONS` | Показ локальных напоминаний о сроке замены картриджа. |
| `SCHEDULE_EXACT_ALARM` | Планирование напоминания на конкретную дату окончания срока службы. |
| `USE_EXACT_ALARM` | То же; рекомендую убрать, см. `AUDIT.md` п. 5.2 — магазины считают его избыточным. |
| `RECEIVE_BOOT_COMPLETED` | Восстановление запланированных напоминаний после перезагрузки телефона. |
| `WAKE_LOCK` | Требуется системе для доставки напоминания в спящем режиме. |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Опционально, по инициативе пользователя: чтобы система не задержала напоминание. |

Сбор данных: **не собираем ничего.** Ни аналитики, ни рекламных SDK, ни идентификаторов,
ни доступа в интернет со стороны приложения. Единственный выход наружу — открытие ссылки
на магазин, которую пользователь сам сохранил, в системном браузере.

## 10. Порядок загрузки версии

1. Консоль → «Приложения» → «Добавить приложение».
2. Загрузить APK из GitHub Release.
3. Заполнить: название, краткое и полное описание, категория, возраст, иконка, скриншоты,
   email поддержки, ссылка на политику конфиденциальности.
4. Тип распространения: **сначала «Закрытое тестирование»** (несколько своих устройств),
   через неделю — «Производственная версия». Это дешёвая страховка от плохих первых отзывов.
5. Отправить на модерацию. Обычно 1–3 рабочих дня.
6. При отказе приходит письмо с конкретной причиной — пришлите мне текст, поправим.

## 11. Как выпускать обновления потом

1. Правим `index.html` (одна задача на версию).
2. Поднимаем `versionName` и `versionCode` в `version.json` **и** строку версии в `index.html`.
3. Дополняем `CHANGELOG.md`.
4. Merge в `main` → запускаем «Build Release APK (RuStore)».
5. Проверяем APK на своём телефоне **установкой поверх** — данные должны остаться.
6. В консоли RuStore: «Версии» → «Создать версию» → загрузить APK → «Что нового» → на модерацию.

Правило без исключений: `versionCode` всегда строго больше предыдущего, ключ подписи всегда тот же.
