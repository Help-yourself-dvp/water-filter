# Скриншоты для магазина

```
raw/     — сюда кладём снимки прямо с телефона: 1.png, 2.png, 3.png …
ready/   — сюда скрипт складывает готовые картинки 1080×1920 для RuStore
```

Порядок работы:

1. Снять экраны на телефоне (какие именно — в `store/SCREENSHOTS.md`).
2. Загрузить файлы в папку `raw/`, назвав их по порядку: `1.png`, `2.png` …
3. Запустить `python3 store/make_store_shots.py`
4. Загрузить в RuStore то, что появилось в `ready/`.

Скрипт вписывает снимок целиком в холст нужного магазину размера, добавляет
фирменный фон и короткую подпись. Ничего не обрезается.
Подписи и порядок задаются в словаре `CAPTIONS` внутри скрипта.
