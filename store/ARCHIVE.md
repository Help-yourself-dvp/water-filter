# Что нужно сохранить у себя (архив на случай удаления репозитория)

Короткий ответ на вопрос «а если я удалю репозиторий и не буду обновлять приложение».

Удалять можно, но **сначала скачайте четыре вещи**. Без них приложение продолжит работать
у всех, кто его уже поставил, но выпустить новую версию и обновить её в магазине
станет невозможно навсегда.

---

## 1. Ключ подписи — самое важное

**Что это.** Файл-печать `debug.keystore` (2 КБ). Android сравнивает печать на установленном
приложении и на новом файле: совпали — обновление ставится поверх с сохранением данных;
не совпали — «Приложение не установлено».

**Где лежит сейчас.** В секрете репозитория `DEBUG_KEYSTORE_BASE64`. Удалите репозиторий —
исчезнет и секрет.

**Что будет без него.** Обновлять приложение в магазине нельзя вообще: RuStore не примет
сборку с другой подписью. Придётся публиковать приложение заново, как чужое,
с потерей всех установок, отзывов и данных пользователей.

**Как сохранить.** Actions → Generate Stable Debug Keystore → скачать артефакт.
Хранить в двух местах: облако + флешка/компьютер.

## 2. Готовый APK

Файл, который вы устанавливаете на телефон и загружаете в магазин.
Скачивается со страницы сборки (раздел Artifacts) или из Releases.
После удаления репозитория пропадут и сборки, и релизы.

## 3. Исходники приложения

Достаточно скачать репозиторий одним архивом: зелёная кнопка **Code** → **Download ZIP**.
Внутри всё: `index.html` (само приложение), файлы сборки, иконки, документация.

Без исходников новую версию собрать не из чего — даже имея ключ подписи.

## 4. Адрес страницы с политикой конфиденциальности

Если она размещена на GitHub Pages этого репозитория, при удалении репозитория ссылка
перестанет открываться, а в карточке магазина останется битой. Модерация к этому
придирается при следующем обновлении.

**Поэтому политику лучше сразу разместить вне GitHub** — см. `store/policy_for_web.txt`,
там инструкция на 3 минуты через telegra.ph.

---

## Что НЕ пострадает, если удалить репозиторий

- Приложение у людей на телефонах — продолжит работать, оно полностью автономно.
- Приложение в магазине — останется опубликованным, его можно будет скачивать.
- Данные пользователей — они на их телефонах, к репозиторию отношения не имеют.
- Другие ваши репозитории — они друг с другом никак не связаны.

## Что пропадёт

- Автоматическая сборка APK (Actions).
- История версий и Releases.
- Секрет с ключом подписи.
- Страница политики, если она была на GitHub Pages.

---

## Рекомендация

Репозиторий бесплатный и места не занимает. Даже если развивать приложение не планируется,
удалять его нет смысла: он не мешает, а в нём лежит вся инфраструктура выпуска.
Если всё же решите удалить — сделайте перед этим четыре пункта выше и сложите их
в одну папку с названием «AquaControl — архив».
