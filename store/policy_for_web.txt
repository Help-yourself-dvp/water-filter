# Текст политики конфиденциальности для страницы в интернете

Этот файл нужен **только для карточки в магазине**: RuStore требует ссылку на страницу
с политикой, доступную любому человеку без входа в аккаунт.

В самом приложении политика уже есть и работает без интернета
(«Настройки» → «О приложении» → «Политика конфиденциальности»), поэтому
пользователь на эту страницу заходить не будет — её открывает только модератор магазина.

---

## Как опубликовать за 3 минуты, без хостинга и без GitHub

1. Откройте в браузере: https://telegra.ph
2. В поле «Title» вставьте: `Политика конфиденциальности AquaControl Pro`
3. В поле «Your name» вставьте: `AquaControl`
4. В большое поле вставьте текст, который начинается ниже, после строки «=== НАЧАЛО ТЕКСТА ===».
5. Нажмите **PUBLISH** вверху справа.
6. Скопируйте адрес получившейся страницы из адресной строки — он выглядит так:
   `https://telegra.ph/Politika-konfidencialnosti-08-17`
7. Этот адрес вставьте в RuStore, в поле «Политика конфиденциальности».

Страница живёт бессрочно и не зависит ни от репозитория, ни от вашего аккаунта GitHub.
Сохраните адрес себе: чтобы позже отредактировать страницу, откройте её **в том же браузере,
где публиковали** — Telegra.ph узнает вас и покажет кнопку «Edit».

Альтернативы, если Telegra.ph не подходит: любая заметка с публичным доступом
(VK, Яндекс Диск с общим доступом на файл, Google Документы «доступ по ссылке»),
или собственный сайт, если он появится.

=== НАЧАЛО ТЕКСТА ===

Политика конфиденциальности приложения AquaControl Pro

Дата вступления в силу: 17 августа 2026 года.
Приложение: AquaControl Pro (com.aquacontrol.pro).

ГЛАВНОЕ

Приложение не собирает, не передаёт и нигде не хранит ваши данные. Всё, что вы вводите,
остаётся в памяти вашего телефона.

КАКИЕ ДАННЫЕ ВЫ ВВОДИТЕ

Названия объектов (например, «Квартира», «Дача»), названия и типы фильтров, срок службы
картриджа, жёсткость воды, количество человек, даты замен, модель и стоимость картриджа,
ссылку на интернет-магазин.

Эти сведения сохраняются только локально, в хранилище приложения на вашем устройстве.
У приложения нет сервера, учётных записей и облачной синхронизации.

ЧЕГО ПРИЛОЖЕНИЕ НЕ ДЕЛАЕТ

Не собирает персональные данные (имя, телефон, электронную почту, адрес).
Не определяет местоположение.
Не обращается к контактам, звонкам, сообщениям, камере, микрофону и фотографиям.
Не содержит рекламы и систем аналитики.
Не использует рекламные идентификаторы.
Не передаёт данные третьим лицам.
Не требует регистрации.

РАЗРЕШЕНИЯ ANDROID

Показ уведомлений — напоминание об окончании срока службы картриджа.
Точные будильники — чтобы напоминание пришло в нужный день, а не с задержкой.
Запуск после перезагрузки — восстановление запланированных напоминаний.
Wake Lock — доставка напоминания, когда телефон спит.
Отключение оптимизации батареи — необязательное, включается только вами вручную.

Все разрешения используются исключительно для локальных напоминаний. Ни одно из них
не связано с передачей данных.

ИНТЕРНЕТ

Приложение работает офлайн. Единственный случай выхода в сеть — если вы сами сохранили
ссылку на интернет-магазин и нажали кнопку перехода: ссылка откроется в вашем браузере,
и дальше действуют правила того сайта.

РЕЗЕРВНЫЕ КОПИИ

По вашей команде приложение сохраняет данные в файл через стандартное окно Android.
Куда положить файл — решаете вы; приложение никуда его не отправляет. Система Android
может включать данные приложения в собственное резервное копирование устройства —
этим управляют настройки телефона, а не приложение.

ДЕТИ

Приложение не адресовано детям и не собирает данных, поэтому не создаёт рисков
для несовершеннолетних пользователей.

УДАЛЕНИЕ ДАННЫХ

Настройки Android → Приложения → AquaControl Pro → Хранилище → Очистить данные.
Либо удалите приложение — данные удалятся вместе с ним. Восстановление возможно
только из вашей резервной копии.

ИЗМЕНЕНИЯ ПОЛИТИКИ

Новая редакция публикуется по этому же адресу с новой датой вступления в силу.

ОБРАТНАЯ СВЯЗЬ

Вопросы по обработке данных можно задать через страницу приложения в магазине.
