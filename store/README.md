# Материалы для карточки магазина

| Файл | Что это |
|---|---|
| `icon-proposal-a-1024.png` | вариант иконки А: белая капля в кольце прогресса на синем градиенте |
| `icon-proposal-b-1024.png` | вариант иконки Б: белая капля с минималистичным циферблатом на синем фоне |

Обе иконки созданы для этого проекта и не содержат чужих водяных знаков,
в отличие от текущего `icon.png` (стоковое изображение PNGTree, см. `AUDIT.md` п. 2.3-бис).

После выбора варианта:

1. выбранный файл становится `icon.png` в корне репозитория (из него сборка сама делает
   все размеры иконок Android);
2. отдельно готовится `icon-512.png` — его загружают в карточку RuStore.

Скриншоты для магазина (4–8 штук, 1080×1920) снимаются на реальном телефоне —
список нужных экранов в `RUSTORE.md`, раздел 7.
