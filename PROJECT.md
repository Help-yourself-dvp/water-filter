# 1. Назначение проекта

AquaControl Pro — полностью автономное Android-приложение для контроля сроков замены картриджей бытовых фильтров воды.

Основная идея проекта — избавить пользователя от необходимости помнить, когда необходимо заменить картридж.

В отличие от обычных напоминаний календаря приложение хранит информацию непосредственно о фильтрах и автоматически рассчитывает срок замены с учетом условий эксплуатации.

Приложение работает полностью локально.

Сервер отсутствует.

Регистрация отсутствует.

Интернет не требуется.

---

# 2. Основные возможности

На текущий момент приложение поддерживает:

- несколько объектов (квартира, дача, родители и т.д.);
- несколько фильтров внутри каждого объекта;
- автоматический расчет срока службы;
- учет количества пользователей;
- учет жесткости воды;
- историю замен;
- учет расходов;
- быстрый переход к покупке картриджа;
- локальные уведомления Android;
- работу без подключения к Интернету;
- хранение всех данных только на устройстве.

# 3. Архитектура проекта

Проект специально сделан максимально простым.

Используется следующая схема:

```
index.html
    │
    │ HTML
    │ CSS
    │ JavaScript
    ▼
Capacitor 5
    ▼
Android WebView
    ▼
APK
```

Практически вся логика приложения находится в одном файле:

```
index.html
```

Это сделано сознательно.

Проект создавался как учебный, поэтому важнее простота понимания, чем разделение на десятки файлов.

Разделение проекта на отдельные JS-модули пока не требуется.

# 6. Основные файлы проекта

## index.html

Главный файл проекта.

Содержит:

- интерфейс;
- стили;
- всю JavaScript-логику;
- работу с localStorage;
- расчет сроков;
- работу с уведомлениями;
- работу модальных окон.

Практически все изменения приложения выполняются именно в этом файле.

---

## build.yml

Основной GitHub Workflow.

Выполняет:

- создание Android-проекта;
- установку зависимостей;
- генерацию иконок;
- создание MainActivity;
- добавление разрешений;
- восстановление постоянного debug.keystore;
- сборку APK.

При обычной разработке изменяется крайне редко.

---

## generate-keystore.yml

Использовался только один раз.

Создает постоянный debug.keystore.

Повторный запуск запрещен.

Если создать новый ключ, Android перестанет считать новые APK обновлением старых, и пользователям придется удалить приложение с потерей всех локальных данных.

---

## icon.png

Исходная иконка приложения.

Из нее во время сборки автоматически создаются все Android-иконки.

---

## manifest.json

Используется только как вспомогательный файл.

Для Android практически не влияет на работу приложения.

---

## README.md

Краткое описание проекта.

Нужен для страницы GitHub.

---

## PROJECT.md

Настоящий документ.

Содержит всю техническую информацию.

Является основным документом проекта.

# 7. Принципы проекта

При разработке соблюдаются следующие правила.

• Максимально простая архитектура.

• Минимальное количество файлов.

• Работа полностью без сервера.

• Работа без регистрации пользователя.

• Хранение данных только локально.

• Минимум внешних зависимостей.

• Любое изменение должно сохранять совместимость со старыми версиями приложения.

• После каждой стабильной версии приложение должно успешно устанавливаться поверх предыдущей версии без удаления данных пользователя.
